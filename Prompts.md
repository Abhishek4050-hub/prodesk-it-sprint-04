
# Prompts.md — Sprint 4

## 1. Project Planning

Prompt:
"Design a beginner-friendly AI Cover Letter Generator using HTML,
CSS, JavaScript, Node.js, Express, and Google Gemini API. Include
a template fallback, secure backend, dark/light mode, and optional
PDF resume parsing."

## 2. UI Development

Prompt:
"Create a modern, responsive SaaS interface for a cover letter
generator. Include candidate details, job description, resume PDF
upload, loading feedback, generated letter preview, copy button,
download button, and dark/light mode. Keep the code simple."

## 3. Backend Development

Prompt:
"Build an Express API endpoint that validates candidate details,
accepts a PDF using Multer, extracts PDF text with pdf-parse,
and generates a professional cover letter using the official
Google GenAI JavaScript SDK."

## 4. Prompt Engineering

Prompt:
"Write a cover letter using the candidate's actual skills,
job role, company, job description, and resume text. Preserve
the supplied facts. Never invent degrees, work history, achievements,
or metrics. Return a professional letter with separate paragraphs."

## 5. Security Review

Prompt:
"Review this Node.js project for exposed API keys, unsafe file
uploads, missing validation, oversized requests, and error handling.
Suggest beginner-friendly improvements."

## 6. Testing

Prompt:
"Prepare test cases for valid form submissions, missing fields,
invalid PDFs, oversized files, missing Gemini keys, API failures,
dark/light mode, copy-to-clipboard, and text downloads."

## Learning Note

I used AI assistance to plan the interface, understand API
integration, develop prompts, and identify testing scenarios.
I reviewed and tested the code as part of my learning process.
